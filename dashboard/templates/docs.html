Documentation

Everything you need to run VeriSync locally and connect it to GitHub.

Overview

VeriSync is a GitHub-native AI code review platform. Every push to main or PR targeting main automatically triggers a review — no manual submission. Each diff chunk is routed through the cheapest AI model that can handle it, paid for in Bitcoin sats via the Lightning Network.

The RL router learns over time which model tier each code pattern actually needs, reducing wasted spend. Every finding is attributed to a model, a cost, and a confidence score.

Setup

1. Clone and install
git clone https://github.com/your-org/verisync
cd verisync
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
2. Register a GitHub OAuth App

Go to GitHub → Settings → Developer settings → OAuth Apps → New OAuth App.

  • Homepage URL: http://localhost:8000
  • Callback URL: http://localhost:8000/auth/callback
  • Scopes needed: repo, read:user, admin:repo_hook
3. Configure .env
GITHUB_CLIENT_ID=your_client_id
GITHUB_CLIENT_SECRET=your_client_secret
GITHUB_REDIRECT_URI=http://localhost:8000/auth/callback
SESSION_SECRET_KEY=generate_with_secrets_token_hex_32
ANTHROPIC_API_KEY=sk-ant-...
OLLAMA_BASE_URL=http://localhost:11434
USE_MOCK_WALLET=true
WEBHOOK_URL=https://your-ngrok-url.ngrok.io/webhook/github
4. Pull Ollama models
ollama pull llama3:8b
ollama pull mistral:7b
ollama pull gemma2:9b
5. Run
python -m router.seed          # seed RL router with synthetic episodes
uvicorn main:app --reload      # start server on :8000

registry.yaml

Add or remove reviewer models by editing this file. The worker factory registers one endpoint per entry on startup.

models:
  - id: llama3-8b          # endpoint slug
    name: "llama3:8b"      # model name passed to provider
    provider: ollama       # "ollama" | "anthropic"
    cost_sats: 5
    endpoint_url: "http://localhost:8000/worker/llama3-8b"
    capability_tags: ["style", "classify"]

  - id: claude-sonnet
    name: "claude-sonnet-4-5"
    provider: anthropic
    cost_sats: 150
    endpoint_url: "http://localhost:8000/worker/claude-sonnet"
    capability_tags: ["security", "architecture", "logic"]

Webhooks

VeriSync registers webhooks automatically when you select a repo from the dashboard dropdown. For local development, expose your server with ngrok: 

ngrok http 8000
# copy the https URL → set as WEBHOOK_URL in .env

GitHub events trigger reviews on: PR opened, PR updated (synchronize), direct push to main. All other branches are silently ignored. Every webhook payload is validated with HMAC-SHA256 — invalid signatures are rejected with HTTP 403.

Cost model

Each worker call deducts cost_sats from the user's wallet. With USE_MOCK_WALLET=true this is in-memory only. The per-chunk cost is fixed in registry.yaml — the router's job is to pick the lowest tier that produces a verified finding.
